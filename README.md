# Pramod Rajpurohit — Portfolio

A responsive, cinematic portfolio for Generative AI Creator & Director Pramod Rajpurohit.

## Included
- Responsive single-page portfolio
- Work gallery with project detail dialogs
- About, skills, experience, education, certifications, and contact sections
- Custom SVG concept artwork in `assets/`
- Scroll reveal motion with reduced-motion support
- Plain HTML, CSS, and JavaScript; no build step required

## Preview locally
Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy
This is a static site. Import the repository into Vercel or Netlify and use the repository root as the project directory. No build command is needed; the output is the root directory.

## Before launch
The SVG images are original concept artwork, not verified stills from the listed productions. Replace these with approved project stills or video previews before presenting the site as a finished production portfolio. Confirm the contact details and external links before public launch.
